# Командные задачи: контролируемое создание агентом

Дата: 2026-10-06, Asia/Tashkent. Область: `executeRunActivitySideEffect` и `task-assignment.integration.spec.ts`.

## Пять проходов критики и исправлений

1. **Доверие.** Новый ответственный не должен стать свободным параметром модели. Сохранили allowlist и хешируемый payload: назначение выводится из доверенного инициатора запуска либо автора определения. Попытка добавить `assigneeId` отвергается до действий и receipts.
2. **Членство.** Существование User не доказывает доступ. Назначаем только `owner/admin/member` развёрнутого рабочего пространства. Отозванный участник или отсутствие членства оставляют задачу без ответственного, сохраняя автора. `FOR SHARE` удерживает проверенную запись членства до конца транзакции.
3. **Повтор выполнения.** Повторное выполнение не должно отменять ручное переназначение. Существующий успешный результат возвращается без изменения activity; транзакционный upsert использует `update: {}`. Тест снимает назначение после первого выполнения и подтверждает, что повтор его не восстанавливает.
4. **История.** Создание TASK и первоначальный `CREATED` сохраняются одной настоящей транзакцией. Существующая activity не получает повторного события. Снимок включает имя ответственного, идентификатор, срок и состояние выполнения; тела задач и секреты в историю не записываются. NOTE не назначается.
5. **Доказательства и изоляция.** Настоящий guarded PostgreSQL 16 в отдельной `tayvero_agent_tasks_test`, 67 миграций. Финальный focused прогон: **5/5, 14 assertions, 0 failures/skips**. Очистка собственных пользователей, task audits и определений агентов подтверждена нулевыми SQL counts. Agent TypeScript прошёл; два прежних optional-chain lint advisories сохранены. Провайдерных вызовов нет.

Независимый предварительный review по пяти линзам не обнаружил подтверждённых P1/P2. Это проверка контролируемого внутреннего исполнения; браузерный UX, native Eve runtime и реальные провайдеры ею не подтверждены. Focused replay проверяет успешный быстрый возврат результата; отдельная инъекция отказа истории/прерывания завершения receipt в этой новой suite не выполнялась. Атомарность этого пути дополнительно проверена чтением исходного кода общей транзакции.
