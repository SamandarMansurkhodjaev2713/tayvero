# Operations and migration UX review — 5 October 2026

Scope: Agent Operations, approval continuations, Migration Center, background import controls and source maintenance. This is a refinement of operating screens using the shared UI and current theme tokens. It changes no runtime, API contract, database, permission, execution flag or approval guard.

## Critique and improvement passes

| Pass | Concrete criticism | Improvement and evidence |
|---|---|---|
| 1. Task hierarchy | Separate metric cards compete with incident work.
