# Product Roadmap

## 0–30 days: production and sellability baseline

Tenant-boundary audit/tests, configurable pipeline design and additive schema, CSV/XLSX import preview, RU/UZ/EN framework, Telegram ingestion, ready-made lead/follow-up/risk agents, agent health/approval queue, deployment and support runbooks.

## 31–60 days: managed pilots

Dry-run/reconciliation import, Bitrix24/Kommo migration adapters, unified inbox, role dashboards, credential encryption, durable jobs/DLQ, backup restore drill, three industry templates and outcome instrumentation.

## 61–90 days: strong Uzbekistan v1

WhatsApp Business, 1C integration boundary, Deal Health, sequences, Agent Builder simple mode, generic webhooks/REST, ROI dashboard, billing/entitlements and PWA hardening.

## 3–6 months: platform differentiation

Custom objects, OpenAPI connector import, MCP client/server, Knowledge/Evidence layer, non-CRM report/document/approval agents, advanced Control Center, model routing and enterprise SSO/RBAC.

## 6–12 months: global beta

Shared control plane, regional/dedicated deployment automation, global billing, connector/template marketplace, public SDK/docs, self-service migration/onboarding, compliance readiness and validated international ICP.
